## Install Indi

- ``install-deps.sh``
- ``clone.sh``
- ``build-all.sh`` - edit which plugins are needed and run
- ``systemctl --user mask gvfs-gphoto2-volume-monitor.service``
- ``systemctl --user stop gvfs-gphoto2-volume-monitor.service``
- to run, use ``run_indi.sh``

location: `/opt/indi`
